# aafaqcs: website of Dr. Aafaq Mohi Ud Din

Academic homepage of **Dr. Aafaq Mohi Ud Din**, Assistant Professor, Department of Computer Science & Engineering, GCET Kashmir.

Live: **https://aafaqcs.netlify.app** (soon **aafaqcs.com**)

- **Research:** graph neural networks, geometric deep learning, publications and projects
- **Video courses:** free visual lectures for GATE CS, GATE DA and JKSSB, playable on the site
- **Teaching:** Design & Analysis of Algorithms, Data Structures, Operating Systems and Compiler Design, with week-by-week slides, practice questions and Google Classroom links

## How it works
A static site generated by plain Python 3, with no frameworks and nothing to install.

```bash
python3 build.py          # writes the whole site into dist/
```

| Folder / file | What it holds |
|---|---|
| `data/profile.json` | bio, news, experience, education, links |
| `data/courses.json` | video courses and YouTube lectures |
| `data/teaching.json` | subjects, week 1–15 topics, Google Classroom links |
| `data/publications.json` | papers and citation metrics |
| `teaching/<subject>/weekNN/` | weekly slides and practice files (see `teaching/README.txt`) |
| `assets/img/` | photo and video thumbnails |

## Publishing
- **Automatic:** Netlify linked to this repository runs `python3 build.py` and publishes `dist/` on every push (`netlify.toml`).
- **By hand:** drag `dist/` onto Netlify → Deploys.
- `push_github.py` pushes this folder to GitHub without needing git installed.
